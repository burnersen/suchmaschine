## Suchmaschine 1.5.4: Unterschriebene Updates

**Deutsch**

- **Updates sind jetzt unterschrieben.** Jedes Release hat neben `suchmaschine-install.php` die Datei `suchmaschine-install.php.sig`. Ab dieser Version spielt die Suchmaschine über *Verwaltung → Update* nur noch Updates ein, deren Unterschrift zum öffentlichen Schlüssel des Projekts passt. Wer ein Release auf GitHub austauscht, kommt damit nicht mehr durch.
- Öffentlicher Schlüssel (Ed25519): `QPO+CSP5Y7S4S5WblMGZRnMl1VT9ypbCJhEVtM3zNoY=`, steht auch in `SECURITY.md` und `app/lib/update.php`.
- Braucht die PHP-Erweiterung `sodium` (bei PHP 8 fast immer dabei). Fehlt sie, meldet die Verwaltung das beim Update, die Installation von Hand mit der Datei geht weiterhin.

**English**

- **Updates are now signed.** Every release ships `suchmaschine-install.php.sig`; from this version on, *Admin → Update* only installs updates whose signature matches the project's public key `QPO+CSP5Y7S4S5WblMGZRnMl1VT9ypbCJhEVtM3zNoY=` (also in `SECURITY.md`). Requires the PHP extension `sodium`.
