## Suchmaschine 3.3.0: Diashow für Bilder

**Deutsch**

- **Diashow** in der Bildvorschau (Brave-Bildersuche) und im Lesezeichen „Bilder groß“ (andere Suchmaschinen): Knopf ▶ oben oder Taste **S** startet und stoppt sie. Daneben wählst du, wie viele Sekunden jedes Bild bleibt (2 bis 60, wird im Browser gemerkt). Nach dem letzten Bild geht es von vorne los. Sie läuft nur, wenn du sie startest, und funktioniert auch im Vollbild.
- Hilfe, Tastenkürzel-Übersicht und README erklären die Diashow.

**English**

- **Slideshow** in the image preview (Brave image search) and in the “Big images” bookmark: ▶ button or key **S** starts and stops it, next to it the seconds per image (2 to 60, remembered in the browser). After the last image it starts over. It only runs when you start it, also in full screen.
