**App-Symbol für den Startbildschirm** / **Home screen icon**

- Wer die Suchmaschine als App auf den Startbildschirm legt (iPhone, Android), bekommt jetzt ein richtiges Symbol statt eines grauen Kastens.
- Mit eigenem Logo wird daraus automatisch das App-Symbol gemacht, auch aus SVG. Ein schon vorhandenes Logo wird beim nächsten Öffnen der Verwaltung nachgerüstet.
- Ändert sich das Logo, bekommt das Symbol eine neue Adresse, damit die Geräte das neue holen. Auf dem iPhone muss man die App dafür einmal neu zum Home-Bildschirm hinzufügen, das ist bei Apple so.

Aktualisieren: Verwaltung → Update → „Nach Updates suchen“ → „Jetzt aktualisieren“.

---

- Adding the search engine to the home screen (iPhone, Android) now shows a proper icon instead of a gray box.
- A custom logo automatically becomes the app icon, SVG included. An existing logo is upgraded the next time the admin page is opened.
- On iPhone, re-add the app to the home screen once to pick up a changed icon.
