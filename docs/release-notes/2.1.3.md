## Suchmaschine 2.1.3: Bangs mit Herkunft (gegen Sperren wie bei Reddit)

**Deutsch**

- **Bangs werden seltener blockiert:** Bisher hat die Suchmaschine beim Weiterleiten gar keine Herkunft mitgeschickt. Manche Seiten, allen voran Reddit, halten solche Aufrufe für Bots und zeigen „You've been blocked by network security“. Jetzt schickt die Weiterleitung, wie DuckDuckGo und Kagi, **nur die Adresse deiner Suchmaschine** mit, **nie den Suchbegriff**. Das gilt für alle Bangs, die zu einer anderen Seite führen.
- Abschaltbar unter *Einstellungen → Bangs → Standard für alle → Liste und Erreichbarkeit*. Aus heißt: wie bisher, gar keine Herkunft.

**English**

- **Bangs get blocked less often:** redirects now send only the address of your search engine as the origin (never the search terms), like DuckDuckGo and Kagi. Sites such as Reddit blocked visits without any origin as suspected bots. Can be turned off under *Settings → Bangs → Default for everyone*.
