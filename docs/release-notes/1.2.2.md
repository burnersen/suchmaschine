## Suchmaschine 1.2.2: Bildvorschau funktioniert immer

**Deutsch**

- **Ein Tipp auf ein Bild öffnet jetzt immer die Großansicht** auf deiner Suchmaschine, nie direkt die fremde Seite. Das gilt auch, wenn der Browser JavaScript blockiert, zum Beispiel durch einen Inhaltsblocker in Safari auf dem iPhone.
- In der Großansicht blätterst du mit den Pfeilen links und rechts weiter. Die Bilder kommen aus dem Zwischenspeicher, das kostet also keine Suche. Zur fremden Seite geht es nur über den Knopf „Seite besuchen“.
- Mit JavaScript bleibt alles wie gewohnt: Wischen, Pfeiltasten, Vollbild, ohne neu zu laden. Eine Großansicht lässt sich jetzt auch als Adresse teilen oder neu laden.

**English**

Tapping an image now always opens the large preview on your search engine, never the other site directly, even when the browser blocks JavaScript (e.g. a content blocker in Safari on iPhone). Browse with the left/right arrows (served from the cache, no extra search); the other site only opens via "Visit page". With JavaScript everything works as before (swipe, arrow keys, full screen).
