## Suchmaschine 3.0.1: Verbrauch laut Dashboard auch für die Hilfen von Brave

**Deutsch**

- **Verbrauch laut Dashboard** gibt es jetzt auch für Suchvorschläge, Rechtschreibhilfe und KI-Antwort (*Verwaltung → Suchdienste*). Praktisch, wenn der Server mitten im Monat neu aufgesetzt wird oder die Keys schon woanders benutzt wurden: Stand aus dem Brave-Dashboard eintragen, der Zähler übernimmt ihn und zählt von da an weiter. Bei der KI-Antwort in Dollar (z. B. 0,62).
- **„Bilder groß“ Schritt für Schritt:** Die Hilfe erklärt jetzt einzeln für Rechner, iPad/iPhone und Android, wie das Lesezeichen eingerichtet und benutzt wird, und was zu tun ist, wenn es nicht klappt (z. B. in der App vom Startbildschirm).

**English**

- **Usage according to dashboard** is now also available for suggestions, spellcheck and AI answers (*Admin → Search services*), handy after setting up the server again mid-month. AI answers are entered in dollars.
- **“Big images” step by step:** the help page now explains setup and use separately for computer, iPad/iPhone and Android, plus what to do if it doesn’t work.
