## Suchmaschine 3.4.0: Bangs aufräumen, kurze Schnipsel, Drucken repariert

**Deutsch**

- **Etiketten repariert:** In der Vorschau und beim Drucken kamen statt Codes nur rote Warndreiecke (Liste, Seriennummern, gleicher Code). Dem Druck-Werkzeug fehlte der Code-Erzeuger. Jetzt klappen alle Formate (QR, Data Matrix, Aztec, Strichcodes).
- **Drucken robuster** (WLAN-Schild, Vorlagen, Etiketten, QR-Studio): Gedruckt wird aus einem eigenen, unsichtbaren Rahmen mit genau der Druckfläche. Papierformat und „Farben exakt drucken“ kommen als Stylesheet vom Server, denn die Sicherheitsregeln (CSP) haben das bisherige eingebettete `@page` still verworfen.
- **Text-Schnipsel mit Pflicht-Passwort und kurzem Link** (`…/?n=Ab3xK9pQ`): Der Schlüssel entsteht im Browser aus dem Passwort (PBKDF2, 600.000 Runden), der lange Teil hinter dem # fällt weg. Ein Zufallspasswort ist schon ausgefüllt. Alte Links funktionieren weiter. Wer einen Schnipsel-Link in die Kurzlinks wirft, bekommt einen verständlichen Hinweis statt einer Fehlermeldung.
- **Bangs verwalten:** komplette Liste mit Seiten, Sprachfilter (Deutsch, Englisch, andere), Häkchen und „Markierte löschen“, Löschen ohne Rückfrage, dafür mit **Rückgängig**. Ein Knopf löscht alle anderssprachigen Bangs auf einmal.
- **Bangs nur noch mit https.** Domains, die per https mehrmals hintereinander nicht antworten, werden für alle automatisch gelöscht (abschaltbar) und kommen zurück, sobald sie wieder antworten.
- Behoben: Rein numerische Bang-Kürzel (z. B. `!1337`) blieben nach dem Löschen nicht gelöscht.
- **Standardsuche für Gäste:** Als Administrator kannst du jede Adresse eintragen, auch einen Startpage-Einstellungslink (`…/mypage.pl?prfe=…`). Er wird zur Suche mit genau diesen Einstellungen. Gäste sehen ihn vorausgewählt als „Standard“, bis sie selbst etwas anderes wählen.
- **Login-Token ohne Spuren im Server-Protokoll:** neue Login-Adresse `…/?a=login#token=…`. Der Teil hinter dem # erreicht nie den Server, ein Skript schickt den Token per POST. `?token=…` geht weiterhin, mit Hinweis zu den Protokollen.

**English**

- **Labels fixed:** previews and prints showed red warning triangles instead of codes. All formats work again.
- **More robust printing** from a dedicated hidden frame; paper size and exact colors come as a stylesheet from the server (the CSP silently dropped the inline `@page`).
- **Text snippets with required password and short link** (`…/?n=Ab3xK9pQ`); the key is derived from the password. Old links keep working.
- **Bang management:** complete paged list, language filter, bulk delete without confirmation but with **undo**, delete all other-language bangs at once.
- **https-only bangs;** domains that repeatedly fail via https are removed for everyone automatically (can be turned off) and come back when they answer again.
- Fixed: purely numeric bang triggers did not stay deleted.
- **Default search for guests:** any address, including a Startpage settings link, preselected for guests.
- **Login token without server log traces:** new login address `…/?a=login#token=…`.
