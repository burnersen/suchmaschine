## Suchmaschine 1.5.0: Aufgeräumt

**Deutsch**

- **Werkzeuge neu sortiert:** Übersicht mit Kacheln nach Gruppen (Rechnen und Umrechnen, Zeit und Datum, Zufall und Entscheidungen, Teilen und Sicherheit, Wetter und Netz). Jedes Werkzeug hat jetzt eine **eigene Seite** statt einer langen Liste, darunter passende weitere Werkzeuge. Alte Links wie `?a=tools#qr` funktionieren weiter.
- **Kachel-Symbol oben rechts** führt von überall zu den Werkzeugen, auch für Besucher, wenn Suchen ohne Anmeldung erlaubt ist.
- **Einstellungen → Browser:** Login-Token und „Als Standardsuche im Browser“ stehen jetzt zusammen. Wetter hat in den Sucheinstellungen einen eigenen Abschnitt.
- **Verwaltung → Aussehen:** Hier legt der Administrator das Aussehen für alle fest (vorher versteckt in den eigenen Einstellungen). Es wird jetzt auch bei „Einstellungen sichern“ mitgesichert.
- **API-Keys holen, Schritt für Schritt** direkt bei jedem Suchdienst in der Verwaltung.
- **Behoben:** Der Name oben auf der Ergebnisseite wurde bei mittleren Bildschirmbreiten abgeschnitten. Die Fußzeile nannte Brave, auch wenn gar kein Dienst eingerichtet war. Ein Administrator ohne Suchdienst wurde zu Startpage weitergeleitet, jetzt kommt ein Knopf „Suchdienst einrichten“. Die Währungskarte ist kompakter, die Wetterquelle in der Verwaltung wird nicht mehr abgeschnitten. Der Hell/Dunkel-Schalter merkt sich die Wahl nur noch für das Verzeichnis der Suchmaschine.
- **Handy:** Reiter in Einstellungen und Verwaltung zeigen mit einem weichen Rand, dass man wischen kann, der aktive Reiter ist immer zu sehen.
- **Für Entwickler:** Code nach Themen aufgeteilt (`router.php`, `page_*.php`, `filters.php`, `domains.php`, `bangs.php` …), englische Texte in `app/lang/en.php`, automatische Tests (`tests/`), Prüfung bei jedem Push mit PHP 8.0 und 8.3, wiederholbarer Bau mit `SHA256SUMS`, Updates auf Wunsch mit Unterschrift (Ed25519). Für Nutzer bleibt es **eine einzige Installationsdatei**. Anleitung: `BUILD.md`.

**English**

- **Tools reorganised:** tile overview by group, every tool on its own page with related tools below, reachable everywhere via the grid icon at the top right. Old links such as `?a=tools#qr` still work.
- **Settings → Browser** now holds the login token and the browser default-search setup. **Admin → Appearance** sets the look for everyone (and is included in the settings backup).
- **Step-by-step API key instructions** next to each search service.
- **Fixed:** site name cut off on the results page, footer naming Brave without any service, admin without a service redirected to Startpage (now gets a “Set up a search service” button), compact currency card, theme cookie limited to the search engine's folder.
- **For developers:** code split by topic, English texts in `app/lang/en.php`, automated tests, CI on PHP 8.0 and 8.3, reproducible builds with `SHA256SUMS`, optional Ed25519-signed updates. Users still get one single installation file. See `BUILD.md`.
