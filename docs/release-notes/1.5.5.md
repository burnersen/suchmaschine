## Suchmaschine 1.5.5: Updates wieder ohne Schlüssel

**Deutsch**

- Die Unterschrift für Updates (seit 1.5.4) ist wieder abgeschaltet. Updates werden wie bis 1.5.3 über die Prüfsummen in der Installationsdatei kontrolliert. So hängt die Weiterentwicklung nicht an einem geheimen Schlüssel, der verloren gehen könnte.
- Dieses Release ist noch ein letztes Mal unterschrieben, damit Installationen mit 1.5.4 es über *Verwaltung → Update* einspielen können.
- Die Unterschrift bleibt als freiwillige Möglichkeit erhalten, zum Beispiel für Forks mit eigenem Schlüssel (`data/config.php`, siehe `BUILD.md`).

**English**

- Update signatures (since 1.5.4) are switched off again; updates are checked by the checksums in the installer as before. This release is signed one last time so 1.5.4 installations accept it. Signing remains available as an option (e.g. for forks), see `BUILD.md`.
