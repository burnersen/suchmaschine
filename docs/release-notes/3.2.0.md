## Suchmaschine 3.2.0: alle Brave-Pläne wie im Dashboard

**Deutsch**

- **Einheitlich für Search, Autosuggest, Spellcheck und Answers:** Jede Karte unter *Verwaltung → Suchdienste* zeigt dasselbe wie das Brave-Dashboard: Requests, Credits remaining, Credits used this month (x $ / 5 $), Burn rate und Runway. Die Dollar werden aus den Requests berechnet, bei Answers mit dem echten Durchschnittspreis.
- **Einstellen musst du nur noch:** Requests laut Dashboard, API-Key, Limit (in Requests), an/aus und „Key entfernen“ (mit Rückfrage). Bei der KI-Antwort gibt es keine Dollar-Felder mehr, die Bremse liegt dort bei 70 Requests.
- **Verwaltung → Verbrauch** zeigt alle vier Pläne genauso und nimmt dort ebenfalls die Requests laut Dashboard an. Verlauf und Verbrauch pro Konto umfassen alle Pläne, die Warnhinweise auch.
- **Zwischenspeicher der Suche:** Standard jetzt 60 Minuten (das Maximum, das Brave erlaubt).
- **Beim Update:** Ein altes Dollar-Limit der KI-Antwort wird zu 70 Requests, der Zähler der KI-Antwort zählt in Requests, die alten Felder „Kosten pro Suche“ und „Stichtag“ verschwinden. Trag nach dem Update einmal die Requests aus deinem Dashboard ein.
- README: reine Funktionsübersicht, die Versionsgeschichte steht in den Releases.

**English**

- All four Brave plans (Search, Autosuggest, Spellcheck, Answers) now look like the Brave dashboard (requests, credits remaining/used, burn rate, runway), with the dollars calculated from the requests. You only enter requests according to the dashboard, the API key, a limit in requests, on/off and “remove key” (with confirmation). The Usage tab shows and accepts the same, history and warnings cover all plans. Search cache defaults to 60 minutes.
