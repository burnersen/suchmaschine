**Besser auf dem Handy** / **Better on phones**

- Verwaltung → Konten: Das Feld „Neues Passwort“ ragte auf schmalen Handys aus dem Bildschirm und ließ sich nur im Querformat bearbeiten. Es erscheint jetzt direkt in der Zeile des Kontos.
- Eingabefelder haben überall mindestens 16 px Schrift, damit das iPhone beim Antippen nicht hineinzoomt.
- Das Suchfeld auf der Ergebnisseite war auf kleinen Handys ein paar Pixel zu breit, die Seite ließ sich dadurch seitlich verschieben. Behoben.
- Die Reiter der Verwaltung brechen auf dem Handy nicht mehr in zwei Zeilen um.
- Alle Seiten wurden auf einem kleinen Handy (iPhone SE) automatisch auf herausragende Elemente geprüft.

Aktualisieren: Verwaltung → Update → „Nach Updates suchen“ → „Jetzt aktualisieren“.

---

- Admin → Accounts: the "New password" field stuck out of the screen on narrow phones. It now opens inside the account row.
- All input fields use at least 16 px text, so iPhones no longer zoom in.
- The search box on the results page was a few pixels too wide on small phones. Fixed.
- Admin tabs no longer wrap into two lines on phones.
